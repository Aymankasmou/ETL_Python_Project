# Orders Data Cleaning and Analysis

A data cleaning and analysis project using Python and Pandas. The project cleans raw order data, handles missing and invalid values, standardizes data, calculates delivery times, and creates visualizations to explore shipping and order patterns.

## Project Overview

The dataset contains order, customer, shipping, and delivery information with several data quality issues.

The project includes:

- Handling missing and invalid values
- Converting and cleaning data types
- Standardizing country, city, and shipping company names
- Cleaning invalid Order IDs
- Calculating delivery days
- Classifying orders as OnTime, Late, or Unknown
- Analyzing shipping costs and order volumes
- Creating visualizations with Matplotlib
- Exporting the cleaned dataset to CSV

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib

## Visualizations

The project includes visualizations for:

- Average Shipping Cost by Country
- Distribution of Delivery Days
- Delivery Status Breakdown
- Monthly Order Volume
